# HIPERFACE Studio 1.2 — راهنمای ساخت فایل اجرایی (EXE)

ترمینال گرافیکی انکودرهای SICK HIPERFACE® روی RS-485 (مطابق سند IM0064865).

> این مخزن فقط شامل سورس و مستندات است. فایل اجرایی (EXE) و دفترچه‌ی رسمی SICK در ریپازیتوری قرار ندارند؛
> EXE را با `build_exe.bat` بسازید و PDF را از لینک رسمی زیر دانلود کنید.

## فایل‌های پروژه
| فایل | کاربرد |
|---|---|
| `hiperface_studio.py` | برنامه‌ی اصلی (رابط کاربری) |
| `hiperface_core.py` | پروتکل HIPERFACE، انکودر شبیه‌سازی‌شده، ابزارها |
| `hiperface_i18n.py` | ترجمه‌ها (انگلیسی / فارسی) |
| `hiperface_help.py` | متن راهنمای داخل برنامه |
| `app.ico` | آیکون |
| `fonts/` | فونت وزیر (Vazirmatn-Regular.ttf و Vazirmatn-Bold.ttf) |
| `get_vazir_font.bat` | دانلود خودکار فونت وزیر در پوشه‌ی fonts |
| `CHANGELOG_FA.md` | تغییرات نسخه 1.2 |
| `build_exe.bat` | ساخت EXE با یک کلیک |
| `run_from_source.bat` | اجرای مستقیم بدون ساخت EXE |

## ساخت EXE
1. **Python 3.8.10 نسخه‌ی 64 بیتی** را نصب کنید (آخرین نسخه‌ای که از ویندوز 7 پشتیبانی می‌کند):
   https://www.python.org/downloads/release/python-3810/ و تیک `Add Python 3.8 to PATH` را بزنید.
2. **(اختیاری)** دفترچه‌ی مستندات `IM0064865` از سایت رسمی SICK دانلود کنید و با همان نام اصلی کنار فایل‌ها (ریشه‌ی پروژه) قرار دهید:
   `operating_instructions_specification_hiperface®_motor_feedback_protocol_en_im0064865.pdf`
   لینک رسمی: https://www.sick.com/media/docs/5/65/865/operating_instructions_specification_hiperface%C2%AE_motor_feedback_protocol_en_im0064865.pdf
   (این فایل بهدلیل کپی رایت در مخزن قرار داده نشده؛ بدون آن هم برنامه از نسخه‌ی آنلاین استفاده میکند.)
3. روی `build_exe.bat` دوبار کلیک کنید. اگر PDF پیدا شود **داخل EXE هم قرار می‌گیرد**. فونت وزیر هم اگر در `fonts` نباشد خودکار دانلود و داخل EXE قرار می‌گیرد.
4. خروجی: `HiperfaceStudio.exe` (روی ویندوز 7، 10 و 11 نسخه‌ی 64 بیتی).

ترتیب جستجوی PDF توسط دکمه‌ی راهنما: فایلی که با «انتخاب فایل PDF…» انتخاب شده ← `D:\PMC\Downloads\Compressed\HiperfaceStudio\<نام PDF>` ← کنار EXE ← پوشه‌ی جاری ← نسخه‌ی داخل EXE ← در نهایت نسخه‌ی آنلاین سایت SICK.
(هر فایل PDF که در نامش `im0064865` باشد پذیرفته می‌شود.)

### نکات ویندوز 7
- ویندوز 7 باید SP1 باشد.
- خطای `api-ms-win-crt-runtime-l1-1-0.dll` ← آپدیت KB2999226 را نصب کنید.
- خطای `SetDefaultDllDirectories` ← آپدیت KB2533623 را نصب کنید.

## امکانات (نسخه 1.2، جزئیات در CHANGELOG_FA.md)
- **دکمه‌ی راهنما (?) و کلید F1**: راهنمای کامل با فهرست قابل کلیک، توضیح همه‌ی دستورها، جدول کدهای خطا،
  رفع اشکال، میانبرها و **لینک باز کردن PDF مستند** (محلی یا آنلاین)
- **دکمه‌ی درباره (i)**: نسخه، توسعه‌دهنده، ایمیل، ریپازیتوری، اطلاعات سیستم و دکمه‌ی کپی اطلاعات
- **آیکون کره + برچسب EN/FA (انتخاب زبان)**: انگلیسی / فارسی با چیدمان راست‌به‌چپ کامل و **فونت وزیر**
- **آیکون خورشید/ماه**: تم تیره و روشن
- زبان، تم و تنظیمات اتصال ذخیره می‌شوند و با تغییر زبان یا تم، اتصال و لاگ حفظ می‌شوند
- همه‌ی امکانات نسخه‌ی قبل: کارت مخصوص برای هر دستور، لاگ رنگی TX/RX، داشبورد زنده، حالت DEMO و ...

میانبرها: `F1` راهنما · `F5` اسنپ‌شات · `Ctrl+L` پاک کردن لاگ · `Ctrl+S` ذخیره‌ی لاگ

## اجرای مستقیم
```
pip install pyserial==3.5
python hiperface_studio.py
```
