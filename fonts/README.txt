Put the Vazirmatn font files here (or run get_vazir_font.bat):
  Vazirmatn-Regular.ttf
  Vazirmatn-Bold.ttf
Source (SIL Open Font License): https://github.com/rastikerdar/vazirmatn
The app loads them privately at start-up (nothing is installed, no admin rights needed)
and build_exe.bat bundles them inside the EXE.
